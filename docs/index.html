    PSOC™ Edge Training - Technical Introduction to PSOC™ Edge E84 Features¶

    This training provides an introduction to key features of the PSOC™ Edge E84 microcontrollers, including audio, graphics, sensor hub, memories, low power modes, and machine learning. The training includes hands-on labs and challenges for each one of these topics, providing a great starting point to getting familiar with PSOC™ Edge.

    Device family¶

    • PSOC™ Edge

    How to use this training?¶

    1. Download the training content
    2. Watch the video or review the presentation at your own pace
    3. Follow the step-by-step instructions in the training manual during the hands-on sections
    4. Use the provided source files if needed to verify the solution

    Training level¶

    • E2: Intermediate

    Prerequisites¶

    Recommended trainings¶

    • This training does not cover basic concepts of ModusToolbox™ and PSOC™ Edge.
    • For an introduction to PSOC™ MCUs, including getting-started guides for ModusToolbox™, go to the PSOC™ Developer Journey.
    • For PSOC™ Edge trainings, from beginner tutorials to advanced trainings, visit the PSOC™ Edge E84 Training Collection.

    Tools (see training manual for versions and installation instructions)¶

    • ModusToolbox™ with Visual Studio Code
    • Edge Protect Security Suite
    • ModusToolbox™ Programming tools
    • Terminal emulator

    Hardware¶

    • KIT_PSE84_EVAL

    Duration¶

    • 4-8 hours, including video and hands-on labs with challenges

    Agenda¶

    1. Getting started
    2. Audio: 2 labs
    3. Sensor hub: 1 lab
    4. Graphics: 2 labs
    5. SMIF: 2 labs
    6. Low power modes: 2 labs
    7. Machine learning: 1 lab including data collection, training, and model deployment

    Expected outcome¶

    • Get hands-on experience with some of the key features and advantages of PSOC™ Edge E84.
    • Get familiar with PSOC™ Edge E84 hardware and software ecosystem.
    • Dive deeper with challenges included for all labs.
